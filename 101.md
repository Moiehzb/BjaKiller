# 101 — Nouveau Projet : Setup & Workflow

Guide à coller dans tout nouveau projet pour ne jamais repartir de zéro.

---

## 1. Git local → GitHub (première fois)

```powershell
# Dans le dossier du projet
git init
git add .
git commit -m "Initial commit"

# Créer le repo sur GitHub (sans README, sans .gitignore)
# puis :
git remote add origin https://github.com/TON_USER/NOM_DU_REPO.git
git branch -M main
git push -u origin main
```

Vérifier que `.gitignore` contient au minimum :
```
node_modules/
dist/
.env
*.keystore
```

---

## 2. Sauvegardes & jalons

**Commit fréquent** — après chaque fonctionnalité stable :
```powershell
git add .
git commit -m "feat: description courte"
git push
```

**Tag de version** avant un gros changement risqué :
```powershell
git tag v0.1-stable
git push origin v0.1-stable
```

Retrouver un tag plus tard : `git checkout v0.1-stable`

**Branche de secours** si tu pars dans une direction incertaine :
```powershell
git checkout -b experiment/nom-feature
# ... travail ...
# Si ça marche → merge dans main
# Si ça foire → git checkout main (branche experiment abandonnée)
```

---

## 3. CLAUDE.md — fichier de contexte projet

À créer à la racine dès le départ. Claude le lit automatiquement à chaque session.

```markdown
# NOM DU PROJET — Description courte

## Lancer l'app
npm install   (une seule fois)
npm run dev   (puis ouvrir http://localhost:5173)

## Stack
- React 18 + Vite (pas de TypeScript)
- Tailwind CSS via CDN
- Lucide React

## Fichiers principaux
- `src/App.jsx` — composant principal
- `src/main.jsx` — point d'entrée

## Direction artistique
[palette, typo, ton éditorial]

## Règles importantes
[contraintes non-évidentes spécifiques au projet]

## Gestion du TODO
`TODO.md` = liste des tâches en cours et backlog.
```

---

## 4. TODO.md — gestion des tâches

Structure minimale :

```markdown
# TODO

## 🔥 En cours
- [ ] tâche active

## 📋 Backlog
- [ ] idée future

## ✅ Fait
- [x] tâche terminée
```

Convention avec Claude : si une tâche manuelle est nécessaire, elle est ajoutée dans TODO.md. Si confirmée faite → déplacée en ✅ Fait.

---

## 5. Stack React + Vite — démarrage rapide

```powershell
npm create vite@latest nom-projet -- --template react
cd nom-projet
npm install
npm install lucide-react
npm run dev
```

Ajouter Tailwind via CDN dans `index.html` (évite le compiler) :
```html
<script src="https://cdn.tailwindcss.com"></script>
```

---

## 6. Récupérer un projet existant depuis GitHub

```powershell
git clone https://github.com/TON_USER/NOM_DU_REPO.git
cd NOM_DU_REPO
npm install
npm run dev
```

---

## 7. En début de session Claude Code

Dire : **"y'a quoi à faire ?"** → Claude lit TODO.md et répond directement.

Pour que Claude soit efficace dès le départ, s'assurer que :
- `CLAUDE.md` existe et est à jour
- `TODO.md` reflète l'état réel des tâches
- Le repo est propre (`git status` clean ou commits en attente connus)

---

## 8. Sécurité / secrets

Ne jamais committer :
- Fichiers `.env` (clés API, secrets)
- Keystores Android (`.keystore`, `.jks`)
- Fichiers de credentials Google/Firebase

Si accidentellement commité : changer les secrets **immédiatement**, puis nettoyer l'historique git.
