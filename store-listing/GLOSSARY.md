# Glossaire — Fiches Google Play

**But :** traduire `store-listing/fr.md` → `store-listing/<locale>.md` **sans rouvrir**
les gros `i18n/locales/*.js`. Les termes ci-dessous sont la terminologie
**canonique de l'app** (extraite des locales) : les réutiliser tels quels pour que
la fiche colle à l'UI que verra le joueur.

**Mode d'emploi :** pour une langue, lire *son* bloc ci-dessous + `fr.md`, produire
`<locale>.md`. Une trad de gabarit ne demande pas Opus → basculer en Haiku/Sonnet
(`/model`). Vérifier ensuite : titre ≤ 30, brève ≤ 80, complète ≤ 4000 caractères.

## Transverse — identique dans TOUTES les langues (ne pas traduire)

- **Titre de l'app :** « HI-LO Academy I » (15 car., jamais traduit)
- **Rangs :** Cuivre · Argent · Or · Émeraude · Saphir · Adamantium (toujours en FR — DA)
- **Nom d'achievement secret :** « The Architect »
- **Noms d'Artefacts/skins :** Classic, Obsidian Void, Steampunk, Cyber, Vapor,
  Eldritch, Norse, Synth, Noir, Cosmos, Bio, Graffiti (seules leurs *descriptions* se traduisent)
- **« Hi-Lo »** : gardé tel quel
- **« blackjack »** : gardé ; en scripts non latins, translittérer selon l'usage local
- **« Académie Secrète… »** : le nom de base est dans chaque bloc ; ajouter l'adjectif
  « secret/secrète » dans la langue (ex. it *Accademia Segreta dei Contatori*, sq *Akademia Sekrete…*)
- **Compteur caché / scellé / bloqué :** utiliser le nom « compteur » (voir bloc) +
  l'adjectif local (caché/scellé/verrouillé) — l'app emploie visible/verrouillé/scellé

> Convention des blocs : `Terme FR (fr.md) → terme canonique cible`, séparés par « · ».
