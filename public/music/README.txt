Dépose ici le fichier exporté depuis LMMS :

    lobby.ogg

Depuis LMMS : File → Export → format OGG Vorbis.
Nomme le fichier exactement "lobby.ogg" et place-le dans ce dossier
(public/music/lobby.ogg). Vite le sert alors à l'URL /music/lobby.ogg,
et l'app le joue en boucle dans le lobby (démarrage au 1er clic).

Aucun autre changement de code nécessaire.
